# Social Discovery AI Motion Proof v0

This directory is a governed, speculative application and portfolio proof for the Social Discovery Group AI Motion Designer (Freelance) opportunity. It is an OBSAD campaign envelope, not commissioned Social Discovery Group work, and it contains no rendered media or performance result.

## What this envelope tests

The opportunity brief supplied for this exercise describes performance motion advertising, short-form channel adaptation, AI-assisted generation, visual consistency, and rapid creative variation. This campaign tests whether one governed visual system can express those capabilities while keeping observation, inference, hook deltas, planned outputs, and provenance separate.

The creative hypothesis is the **Connection Nucleus**: a dominant pearl-like core and a smaller echo core held in a fixed gilded orbit. It gives the proof a repeatable identity atom that can survive prompt, model, edit, and channel changes without becoming a product claim or an employer claim.

## Current pipeline stage

`OBSERVATIONS → INFERENCES → IDENTITY CONTRACT → CONTROLLED HOOKS → PLANNED OUTPUTS → VALIDATION → RECEIPT`

This commit stops before generation, selection, assembly, QA, and publication. Every media output is explicitly planned or null. Provider declarations describe future execution paths; they are not evidence that a provider has been run.

## Approved hook set

Three opening hypotheses are recorded in [`tasks/hook-variants.yaml`](tasks/hook-variants.yaml):

- **A — Absence to arrival:** an empty field is answered by the nucleus.
- **B — Curiosity to recognition:** a material macro view resolves into the relational object.
- **C — Noise to signal:** surrounding fragments quiet while the nucleus remains stable.

Only the opening visual event, opening copy, initial camera behavior, and initial audio transient may change. All variants converge toward the same body at approximately 1.2 seconds.

## Intended uses

- **Job application proof:** show a hiring reviewer a complete, governed motion-ad system rather than an isolated generation.
- **Paid-trial bootstrap:** provide a safe starting envelope if a prospective client later supplies an actual product, approved messaging, brand assets, permitted claims, audience, CTA, and delivery constraints.
- **Portfolio case study:** derive a readable system breakdown while keeping this repository campaign as the canonical source.
- **OBSAD regression specimen:** test controlled hook variation against identity drift once a real execution is authorized.
- **Cross-provider experiment:** compare validated providers later without allowing provider behavior to rewrite the observations.

## Evidence boundary

The supplied opportunity brief is treated as the source for role-scope observations. Repository capabilities are recorded separately. The Connection Nucleus, hook triad, and performance-oriented structure are creative inferences and must not be presented as employer requirements. There is no verified client product, paid commission, campaign baseline, CTR, CPA, conversion, watch-time, ROAS, or hook-rate evidence in this envelope.
