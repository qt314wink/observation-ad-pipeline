# Case study: from observation to movement

## Argument

Health information becomes useful to a broad audience only when it is made understandable. The campaign turns that observation into one memorable mechanism: a directional light signal causally survives every scale change until it motivates focus, reach, connection, and a typography-safe hold.

## Proof chain

| Stage | Evidence |
|---|---|
| Observation / inference | separately typed records in `observations/evidence.yaml` |
| Contract / tokens | governed invariants in `creative-contract.json` and `tokens.json` |
| Prompt | one ordered semantic prompt compiled through thin provider adapters |
| Model / workflow | runtime-configured model fields and a patchable staged Wan graph |
| Candidates | immutable generation ledger and per-run receipts (empty pending runtime) |
| Evaluation | weighted QA with healthcare safety and technical integrity blockers |
| Reject / select | rejection ledger and explicit candidate status; no fabricated results |
| Assembly / adaptation | eight isolates, timed storyboard, and master-derived crop contracts |
| Final | asset manifest truthfully remains planned until approved media and QA exist |

## Creative rationale

The first pulse supplies a stop reason, the scale translation supplies a continue/watch reason, and the surviving light path supplies recognition and recall. Documentary human framing prevents the microscopic language from becoming a biotech spectacle. Typography remains a deterministic finishing operation.

## Current outcome

This branch is a validated production package and portfolio process artifact, not a fabricated finished film. It includes the complete build order, dry-run compilation, controlled graph template, evaluation rules, and final-delivery contracts. Generative execution, candidate imagery, assembled motion, and channel media are intentionally deferred until compatible runtimes and configured models are available.
