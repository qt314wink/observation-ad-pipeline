# Reuse candidate report

## Implemented generically

- `campaign-contract.schema.json` models provider-neutral campaign intent, targets, safety, and QA without Calcium naming.
- `obsad.campaign` provides deterministic ordered compilation, adapter selection, configuration-driven model resolution, hashes, and cross-file validation.
- CLI campaign validation and compilation can serve another campaign following the same package contract.

## Campaign-specific

Positioning, copy, colors, materials, observations, shots, motion beats, provider notes, safety language, and Calcium application context stay below this campaign namespace.

## Future candidates (deferred)

- Formal JSON schemas for keyframe lineage, isolate tasks, candidate receipts, rejection taxonomies, and final assets after a second campaign proves the abstraction.
- A generic weighted-QA scorer after real candidate receipts establish calibration behavior.
- Deterministic FFmpeg crop/type recipes after approved masters establish focal points and type layouts.
- Installed-node-aware Wan workflow selection; this repository currently has no runtime capability registry.
