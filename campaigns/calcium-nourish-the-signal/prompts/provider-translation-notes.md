# Provider translation notes

All adapters consume `semantic.yaml` in the fixed compiler order. OpenAI emphasizes semantically consistent keyframes; xAI uses concise exploration and motion language; ComfyUI moves repeatability controls into nodes; Wan is a staged ComfyUI video path. The provider and model are execution configuration, not conceptual authority.

Model identifiers intentionally resolve from the environment names in `creative-contract.json`; no stale identifier is silently selected. Generated text is prohibited, with copy reserved for deterministic post-production.
