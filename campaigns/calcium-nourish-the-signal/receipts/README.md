# Receipt contract

Each executed candidate gets one immutable JSON receipt named for its run ID. Required fields are campaign and contract hashes, task/keyframe/isolate ID, provider, model/checkpoint family and license, seed, prompt hash and values, reference hashes, workflow hash and node patches where applicable, output hashes, selection status, rejection reason when rejected, and QA result.

This directory contains no execution receipts because no provider runtime was available. A planned task is never treated as a generated candidate.
